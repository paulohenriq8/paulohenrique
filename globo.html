Manter Dashboard da GLOBO Sempre Ativo

Guia oficial para intérpretes OPI/VRI evitarem a desconexão automática de 10 minutos sem bloquear a webcam e sem cair da fila.

1
Instalar o Tampermonkey no Navegador
Instale a extensão oficial Tampermonkey no Chrome, Edge ou Brave através da Chrome Web Store. Fixe o ícone da extensão ao lado da barra de endereços.
2
Criar o Script de Presença Automatizado
Clique no ícone do Tampermonkey e escolha "Criar novo script...". Apague todo o conteúdo que surgir no editor e cole o código validado abaixo:
globo_keepalive_v9.1.user.js 
// ==UserScript==
// @name         Keep Alive GLOBO - Definitivo Confirmado
// @namespace    http://tampermonkey.net/
// @version      9.1
// @description  Mantém a fila da GLOBO ativa alternando abas de Assignments e consultando histórico
// @match        https://globohq.com/linguist_dashboard/*
// @grant        none
// ==/UserScript==

(function() {
    'use strict';

    // Intervalo de 3 minutos e 30 segundos (210.000 ms)
    const INTERVALO_MS = 210000;

    function dispararKeepAlive() {
        const horaAtual = new Date().toLocaleTimeString();
        console.log(`%c[GLOBO Keep-Alive] Pulso de presença iniciado às: ${horaAtual}`, 'color: #00bcd4; font-weight: bold;');

        // 1. Manutenção de sessão silenciosa via rede (My Video Call History)
        const linkHistorico = Array.from(document.querySelectorAll('a, span')).find(el => {
            const txt = (el.textContent || '').trim().toLowerCase();
            return txt.includes('my video call history') || txt.includes('my telephone call history');
        });

        if (linkHistorico && linkHistorico.closest('a')) {
            const urlDestino = linkHistorico.closest('a').href;
            fetch(urlDestino, { credentials: 'include' })
                .then(() => console.log('%c[GLOBO Keep-Alive] Histórico consultado com sucesso via rede.', 'color: #4caf50;'))
                .catch(() => {});
        } else {
            fetch(window.location.href, { credentials: 'include' }).catch(() => {});
        }

        // 2. Interação nativa nas abas de 'Assignments' (Tomorrow -> Today)
        const abas = Array.from(document.querySelectorAll('a, button, li'));
        const abaTomorrow = abas.find(el => (el.textContent || '').trim().toLowerCase() === 'tomorrow');
        const abaToday = abas.find(el => (el.textContent || '').trim().toLowerCase() === 'today');

        if (abaTomorrow && abaToday) {
            abaTomorrow.click();
            console.log('[GLOBO Keep-Alive] Aba "Tomorrow" acionada.');

            setTimeout(() => {
                abaToday.click();
                console.log('%c[GLOBO Keep-Alive] Regresso à aba "Today" concluído.', 'color: #4caf50; font-weight: bold;');
            }, 1500);
        }
    }

    // Primeiro teste automático 5 segundos após abrir a página
    setTimeout(dispararKeepAlive, 5000);

    // Repete no intervalo programado
    setInterval(dispararKeepAlive, INTERVALO_MS);
})();
3
Guardar e Ativar na Plataforma
Prima Ctrl + S no Tampermonkey para guardar. Abra o separador do painel (globohq.com/linguist_dashboard/index) e recarregue com F5 apenas uma vez.
Porque este método é seguro

Ele alterna as abas Tomorrow e Today e envia pedidos assíncronos ao histórico sem tocar no botão de preview de vídeo. A câmara e a chamada WebRTC ficam 100% livres para receber atendimento.

Evite recarregadores automáticos (Auto-F5)

Extensões que forçam F5 na página desconectam o WebRTC do Twilio da central, retirando o intérprete da fila e causando perda direta de chamadas.
