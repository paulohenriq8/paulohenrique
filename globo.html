Mantenha o Dashboard da GLOBO Ativo Sem Cair a Cada 10 Minutos

Chega de ser deslogado da fila enquanto aguarda chamadas de OPI ou VRI. Este método realiza um micro-clique automático no botão Show Preview a cada 5 minutos, mantendo sua sessão 100% online sem interferir em atendimentos.

Sem F5 ou Reload

Não recarrega a página inteira, preservando a conexão WebRTC da fila.

Clique Real no Botão

Clica no Show Preview, acionando o ping de atividade exigido pela GLOBO.

Auto-Fechamento (3s)

Se abrir a câmera de preview, fecha em 3 segundos para poupar dados e CPU.

Por que apenas mexer o mouse não funcionou?

A plataforma da GLOBO possui um monitoramento rígido: quando demora para cair chamada, ela ignora eventos virtuais de mouse e exige uma ação real de interface a cada 10 minutos (como abrir histórico ou testar câmera).

Identificamos no código o botão específico de teste de vídeo: button.btn.btn-info.btn-sm.mb-2 com texto "Show Preview". Clicar nele a cada 5 minutos engana perfeitamente o timeout sem desconectar você!

Código para o Tampermonkey

Basta clicar no botão acima para copiar. Este código está pré-configurado especificamente para a URL e os seletores do Dashboard da GLOBO:

globo_preview_autoclick.user.js
Intervalo: 5 min 
// ==UserScript==
// @name         Keep Alive GLOBO - Show Preview Auto-Click
// @namespace    http://tampermonkey.net/
// @version      3.0
// @description  Clica no botão Show Preview para manter a sessão ativa na GLOBO
// @match        https://globohq.com/linguist_dashboard/*
// @grant        none
// ==/UserScript==

(function() {
    'use strict';

    // Intervalo de 5 minutos (300.000 ms) — a GLOBO desloga com 10 min
    const INTERVALO_MS = 5 * 60 * 1000;

    function encontrarBotaoPreview() {
        // 1. Procura pelas classes nativas inspecionadas no botão da GLOBO
        const botoes = Array.from(document.querySelectorAll('button.btn-info, button.btn-sm, button'));
        
        // 2. Filtra pelo texto "Preview" (compatível com Show Preview / Hide Preview)
        return botoes.find(el => {
            const texto = (el.innerText || el.textContent || '').toLowerCase();
            return texto.includes('preview');
        }) || document.querySelector('button.btn.btn-info.btn-sm.mb-2');
    }

    function dispararKeepAlive() {
        const btn = encontrarBotaoPreview();

        if (btn) {
            btn.click();
            console.log('[GLOBO Keep-Alive] Ping executado em "Show Preview":', new Date().toLocaleTimeString());

            // Se abrir a prévia de câmera/vídeo, fecha após 3 segundos para economizar recursos
            setTimeout(() => {
                const btnAberto = encontrarBotaoPreview();
                if (btnAberto && (btnAberto.innerText || '').toLowerCase().includes('hide')) {
                    btnAberto.click();
                    console.log('[GLOBO Keep-Alive] Preview fechado automaticamente após o ping.');
                }
            }, 3000);

        } else {
            console.warn('[GLOBO Keep-Alive] Botão Show Preview não localizado nesta tela.');
        }
    }

    // Executa o primeiro ping de validação 6 segundos após a página carregar
    setTimeout(dispararKeepAlive, 6000);

    // Agenda execuções automáticas contínuas a cada 5 minutos
    setInterval(dispararKeepAlive, INTERVALO_MS);
})();

Passo a Passo de Instalação

ETAPA 01

Instalar a Extensão Tampermonkey

Adicione a extensão no seu navegador padrão de trabalho (Chrome, Edge ou Firefox).

Chrome Web Store Edge Add-ons
ETAPA 02

Criar Novo Script & Limpar

Clique no ícone preto do Tampermonkey na barra de extensões e escolha "Criar novo script...". Apague todo o texto padrão da tela preta.

Deixe a janela do editor completamente vazia antes de colar.
ETAPA 03

Colar o Código e Salvar

Cole o código do bloco acima e salve apertando Ctrl + S (ou menu Arquivo > Salvar).

O script já fica ativado automaticamente após salvar.
ETAPA 04

Recarregar a GLOBO (F5)

Volte para a aba do globohq.com/linguist_dashboard/index e pressione F5 uma única vez.

Pronto! O robô assume e dá o primeiro clique em 6 segundos.
