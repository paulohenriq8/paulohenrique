Guia de Manutenção de Sessão Ativa

Sem F5 • Sem Queda de Chamadas • 100% Seguro

Evite a Desconexão por Inatividade no GLOBO Dashboard

Tutorial passo a passo para manter seu status disponível na fila de interpretação OPI/VRI sem precisar reiniciar ou mexer manualmente no computador.

Sem Recarregar a Tela

Não quebra a conexão WebRTC de áudio e vídeo.

100% no Navegador

Roda só na aba da GLOBO e sem programas pesados.

Sinal a cada 45s

Simula micro-movimentos sem travar o ponteiro.

01

Instalar a extensão Tampermonkey

O Tampermonkey é um gerenciador de scripts para navegadores seguro e amplamente utilizado no mundo inteiro. Escolha o seu navegador abaixo e instale a extensão oficial:

Google Chrome
Microsoft Edge
Mozilla Firefox
Dica: Lembre-se de clicar no ícone de "quebra-cabeça" do Chrome e fixar o Tampermonkey na barra superior para vê-lo sempre.
02

Criar um Novo Script

Abra as opções da extensão para adicionar o comando customizado:

  1. Clique no ícone preto do Tampermonkey no topo do navegador.
  2. Clique na opção "Criar novo script..." (ou "Create a new script").
  3. Uma janela preta de editor de código se abrirá. Selecione todo o texto de exemplo e APAGUE tudo até a tela ficar em branco.
03

Copiar e Colar o Código

Copie o bloco de código abaixo e cole no editor do Tampermonkey que você acabou de limpar:

globo_keepalive.js Destino: globohq.com 
// ==UserScript==
// @name         Keep Alive GLOBO Linguist Dashboard
// @namespace    http://tampermonkey.net/
// @version      1.1
// @description  Evita desconexão por inatividade no Linguist Dashboard da GLOBO
// @match        https://globohq.com/linguist_dashboard/*
// @grant        none
// ==/UserScript==

(function() {
    'use strict';

    // Dispara a cada 45 segundos para manter a sessão ativa
    setInterval(() => {
        // Simula micro-movimento do mouse (não interfere na sua mira/cliques)
        const evt = new MouseEvent('mousemove', {
            view: window,
            bubbles: true,
            cancelable: true,
            clientX: Math.floor(Math.random() * 200),
            clientY: Math.floor(Math.random() * 200)
        });
        document.dispatchEvent(evt);

        // Garante foco na janela do navegador
        window.dispatchEvent(new Event('focus'));

        // Registro silencioso de atividade
        console.log('[GLOBO Keep-Alive] Atividade simulada com sucesso:', new Date().toLocaleTimeString());
    }, 45000);
})();
04

Salvar e Recarregar a Plataforma

1. Salve o Script:

No editor do Tampermonkey, vá no menu Arquivo (File) > Salvar (Save) ou simplesmente aperte Ctrl + S.

2. Recarregue a Plataforma GLOBO:

Abra a sua aba do https://globohq.com/linguist_dashboard/index e pressione F5 uma única vez para carregar o script.

Dúvidas Frequentes & Boas Práticas

Por que não usar um Auto-Refresh de página comum (F5)?

Recarregar a página com F5 destrói a sessão WebRTC de áudio e vídeo em andamento. Se uma chamada tocar no exato segundo do reload, ela é rejeitada automaticamente e você pode levar advertência na plataforma. O nosso script não atualiza a página, ele apenas gera pulsos internos no mouse.

O script pode clicar em alguma coisa e aceitar chamada sem querer?

Não! O script dispara apenas eventos de mousemove (movimentação do mouse) em coordenadas neutras. Ele não executa eventos de click em botões.

Posso deixar a plataforma online e sair de casa?

Atenção: Não recomendamos se afastar do posto de trabalho por longos períodos enquanto estiver "Disponível". Se uma chamada tocar e você não atender no tempo limite, o sistema registra como "Chamada Perdida" (Missed Call) no relatório de aderência do linguista.
