Download do Extrator de Chave Kindle KFX e Como Extrair a Chave do Kindle KFX

Tradução em Português | Conteúdo adaptado do artigo original da Epubor.

O Kindle KFX Key Extractor (ou Extrator de Chave Kindle KFX) é uma ferramenta essencial para usuários que desejam fazer backup de seus e-books do Kindle. Neste guia completo, você aprenderá como baixar essa ferramenta e como extrair com sucesso a chave de criptografia dos arquivos no formato Kindle KFX para remoção de DRM no Windows.

Método 1: Extrair a chave KFX do app Kindle para Windows 11 (App Store)

Se você estiver utilizando o aplicativo Kindle baixado diretamente da Microsoft Store no Windows 11, siga as etapas abaixo para extrair a chave KFX e converter os livros.

  1. Baixe os e-books do Kindle para acesso offline através do aplicativo Kindle para Windows (instalado via Microsoft Store).
  2. Baixe a versão mais recente das ferramentas DeDRM: Download DeDRM Tools. Extraia o arquivo .zip baixado.
  3. Localize e execute o arquivo MSIXKFXArchiver.exe contido dentro do diretório das ferramentas DeDRM extraídas.
Figura 1: Execução do utilitário MSIXKFXArchiver.exe
  1. O programa irá ler os livros armazenados pelo app da Microsoft Store, gerando automaticamente uma pasta chamada archived_kfx contendo o arquivo de chave oldbooks.k4i e os arquivos em formato .kfx-zip.
Figura 2: Arquivos gerados na pasta archived_kfx
  1. Abra o software Calibre. Se ainda não tiver o plugin KFX Input instalado, acesse Preferências > Plugins > Obter novos plugins, busque por KFX Input e faça a instalação.
  2. Arraste o arquivo .kfx-zip gerado para a interface do Calibre. O livro será importado e o DRM removido com sucesso.
Figura 3: Livro importado sem DRM no Calibre

Método 2: Extrair a chave KFX usando Kindle para PC v2.9.x no Windows 10 e 11

Para quem utiliza as versões clássicas do programa Kindle para PC (versão 2.9.1 ou similar), o processo de extração exige o uso da linha de comando.

  1. Instale o software Calibre e a versão específica do aplicativo Kindle para PC (v2.9.1).
  2. No Calibre, acesse Preferências > Plugins > Carregar plugin de um arquivo e instale os plugins DeDRM_plugin.zip e KFX Input.zip. Reinicie o Calibre após a instalação.
  3. Copie o executável KFXArchiver291.exe (encontrado no pacote do DeDRM) para a pasta de instalação do app Kindle:
    C:\Users\SEU_USUARIO\AppData\Local\Amazon\Kindle\application
Figura 4: Localização correta do KFXArchiver291.exe
  1. Abra o Kindle para PC, faça login na sua conta Amazon e baixe todos os livros que deseja converter.
  2. Crie uma nova pasta em seu computador onde os arquivos processados serão salvos (por exemplo: C:\Users\SEU_USUARIO\kfxoutput).
  3. Abra o Prompt de Comando (CMD) do Windows e execute a seguinte linha de comando (substituindo SEU_USUARIO pelo seu nome de usuário no Windows):
C:\Users\SEU_USUARIO\AppData\Local\Amazon\Kindle\application\KFXArchiver291.exe "C:\Users\SEU_USUARIO\Documents\My Kindle Content" "C:\Users\SEU_USUARIO\kfxoutput" kfxoutput.k4i
Figura 5: Comando executado no Prompt de Comando
  1. Após a conclusão da execução do comando, abra a pasta de destino (kfxoutput). Você encontrará os livros convertidos e a chave extraída.
  2. Importe os arquivos resultante .kfx-zip para o Calibre para convertê-los livremente para EPUB, PDF ou MOBI.
