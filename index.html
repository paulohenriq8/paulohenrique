Converter Livros Kindle para ePub e PDF sem DRM (Formato KFX-ZIP)

Guias de Leitura Digital Atualizado em 2026 Leitura de 8 min

Com a ajuda das recentes atualizações do plugin DeDRM v10.0.31 para o Calibre, tornou-se possível remover o DRM de edições recentes de e-books Kindle. O novo conjunto de ferramentas inclui utilitários essenciais para extrair chaves criptográficas de livros baixados diretamente pelo aplicativo Kindle para Windows e versões legadas do Kindle para PC.

Soluções Disponíveis

Solução 1: DeDRM V10.0.31 + MSIXKFXArchiver + Kindle para Windows (Microsoft Store)
Recomendado para usuários do Windows 11 utilizando a versão moderna da Microsoft Store.
Solução 2: DeDRM V10.0.20 + KFXArchiver + Kindle para PC V2.9.1
Ideal para ambientes Windows 10 e Windows 11 utilizando o instalador clássico.
Aviso Legal

Este guia foi elaborado estritamente para fins educacionais e de backup pessoal de livros que você adquiriu legalmente. A remoção de proteção DRM pode violar os termos de serviço do fornecedor. Não redistribua nem comercialize os arquivos convertidos. Sempre verifique a legislação de direitos autorais vigente em seu país.

1 Extrair Chaves KFX pelo Aplicativo Kindle da Microsoft Store (Windows 11)

No Windows 11, o aplicativo Kindle é obtido através da Microsoft Store. O Calibre e os novos scripts de arquivamento conseguem processar esses arquivos diretamente.

Passo 01

Baixe os livros para leitura offline

Abra o aplicativo Kindle baixado da Microsoft Store e realize o download completo dos e-books desejados para o seu dispositivo.

Passo 02

Baixe a versão mais recente do DeDRM Tools

Acesse o repositório oficial de ferramentas DeDRM, baixe o arquivo DeDRM_tools.zip e descompacte seu conteúdo em uma pasta local.

Passo 03

Execute o utilitário de extração

Dentro da pasta descompactada, execute o arquivo executável relativo à sua versão:

MSIXKFXArchiverMobi1_xxxxx.exe

Este script extrai os arquivos DRM e cria uma pasta chamada archived_kfx contendo os e-books em formato .kfx-zip livres de proteção.

Passo 04

Instale o plugin KFX Input no Calibre

Adicione o plugin de entrada KFX ao Calibre (Preferências > Plugins > Carregar plugin de um arquivo). Esta etapa é obrigatória para prevenir erros na leitura dos pacotes KFX-ZIP.

Passo 05

Importe e converta para ePub ou PDF

Arraste os arquivos da pasta archived_kfx para o Calibre. Os livros serão interpretados como formato KFX e poderão ser convertidos para ePub, PDF ou AZW3 usando o botão "Converter livros".

2 Ambiente Windows 10 / Kindle para PC Clássico

Se você utiliza o aplicativo tradicional do Kindle para PC (versões 2.8.x a 2.9.x), siga os passos abaixo para configurar os plugins e extrair a chave .k4i.

1. Preparar o Calibre e os Plugins

  • Instale a versão mais recente do Calibre.
  • Baixe e instale o plugin KFX Input v2.34.0 no Calibre.
  • Adicione o arquivo DeDRM_plugin.zip nas preferências de plugins do Calibre.

2. Copiar o Executável Archiver para a Pasta da Aplicação

Copie o arquivo KFXArchiver291.exe para o diretório raiz do aplicativo Kindle no seu computador (geralmente localizado em):

C:\Users\<seu_usuario>\AppData\Local\Amazon\Kindle\application\

3. Criar a Pasta de Saída e Gerar o Arquivo de Chave (.k4i)

Crie uma nova pasta chamada kfxoutput no diretório do seu usuário (C:\Users\<seu_usuario>\kfxoutput).

Abra o Prompt de Comando (cmd) e execute a linha de comando correspondente:

C:\Users\<seu_usuario>\AppData\Local\Amazon\Kindle\application\KFXArchiver291.exe "C:\Users\<seu_usuario>\Documents\My Kindle Content" "C:\Users\<seu_usuario>\kfxoutput" kfxoutput.k4i
Resultado esperado: O console exibirá Writing DSN and secrets into kfxoutput.k4i. O arquivo de chave gerado será salvo no diretório configurado.

4. Personalizar o Plugin DeDRM no Calibre

Vá em Calibre > Preferências > Plugins > DeDRM > Personalizar Plugin. Selecione "Kindle for Mac/PC ebooks" e importe o arquivo kfxoutput.k4i gerado. Reinicie o Calibre.

Diagnóstico e Solução de Erros Comuns

O arquivo importado aparece como KFX-ZIP no Calibre?

Isso indica que a descriptografia falhou. Verifique se a pasta kfxoutput foi criada corretamente antes de executar o comando e certifique-se de importar arquivos da pasta de saída, não os arquivos .azw originais.

Erro "Could not get any secrets" no Windows 11?

Mova o utilitário MSIXKFXArchiver para a raiz do disco (C:\Data) e execute novamente como Administrador. Certifique-se também de que o módulo TPM está ativo no seu sistema.

Passo a passo para o download de novos livros

Sempre que baixar novos e-books no aplicativo Kindle, esvazie os arquivos da pasta kfxoutput, remova o arquivo .k4i antigo e execute o comando no terminal novamente para renovar as chaves de sessão.

Guia técnico independente de conversão de formatos e-book.

Kindle, Windows e Calibre são marcas registradas de seus respectivos detentores.
