Como Baixar o Kindle KFX Key Extractor e Extrair Chaves do Kindle KFX

Artigo original publicado por Epubor | Traduzido para português.

Visão Geral

Com o auxílio de ferramentas como o plugin DeDRM v10.0.32 e o KFXArchiver para Calibre, é possível obter a chave criptográfica de livros Kindle baixados pelo aplicativo Kindle para Windows para leitura e backup pessoal.

Método 1: Windows 11 (Aplicativo Kindle da MS Store)

  1. Baixe seus livros Kindle para acesso offline através do aplicativo Kindle para Windows (Microsoft Store).
  2. Baixe e descompacte a versão mais recente do DeDRM_tools.zip (v10.0.32 ou superior).
  3. Execute o utilitário MSIXKFXArchiver.exe contido na pasta extraída. Ele processará os arquivos e gerará a pasta archived_kfx com os arquivos sem DRM e a chave oldbooks.k4i.
  4. No Calibre, instale o plugin KFX Input (arquivo .zip sem descompactar).
  5. Arraste os arquivos .kfx-zip da pasta archived_kfx para a biblioteca do Calibre. Eles serão convertidos para KFX sem DRM e poderão ser exportados para EPUB ou PDF.

Método 2: Windows 10 e 11 (Kindle para PC v2.9.x)

  1. Instale o Calibre e o aplicativo Kindle para PC (v2.9.1).
  2. No Calibre, navegue em Preferências > Plugins > Carregar plugin de arquivo e instale o DeDRM_plugin.zip e o KFX Input.zip. Reinicie o Calibre.
  3. Copie o arquivo KFXArchiver291.exe da pasta dos plugins DeDRM para o diretório raiz do aplicativo Kindle (geralmente em C:\Users\SEU_USUARIO\AppData\Local\Amazon\Kindle\application).
  4. Abra o Kindle para PC, faça o login e baixe os livros desejados para offline.
  5. Crie uma pasta chamada kfxoutput no seu diretório de usuário (ex.: C:\Users\SEU_USUARIO\kfxoutput).
  6. Abra o Prompt de Comando (cmd) e execute o comando: 
    C:\Users\SEU_USUARIO\AppData\Local\Amazon\Kindle\application\KFXArchiver291.exe "C:\Users\SEU_USUARIO\Documents\My Kindle Content" "C:\Users\SEU_USUARIO\kfxoutput" kfxoutput.k4i
  7. Copie os arquivos .kfx-zip gerados dentro de kfxoutput para a biblioteca do Calibre para obter as versões desbloqueadas em EPUB/PDF.
